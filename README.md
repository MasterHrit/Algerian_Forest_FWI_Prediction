#  Algerian Forest Fire Prediction

## Overview
This project is a machine learning model that predicts forest fire risk using environmental and meteorological data from the Algerian Forest Fire dataset.

---

##  Live Demo
Try the deployed application here:  
👉 **https://algerian-forest-fwi-prediction.onrender.com**

---

## Workflow
- Data preprocessing  
- Exploratory Data Analysis (EDA)  
- Feature selection  
- Model training  
- Model evaluation  
- Model serialization (saving model)  
- Deployment  

---

## Models Used
- Linear Regression
- Ridge Regression  
- Lasso Regression  
- ElasticNet

---

## Evaluation Metrics
Model performance is evaluated using:
- Accuracy / R² Score  
- Mean Absolute Error (MAE)  
- Mean Squared Error (MSE)
